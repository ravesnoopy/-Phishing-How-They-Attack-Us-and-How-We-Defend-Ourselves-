> ⚠️ All emails, company names, and numbers in this repository are **fictitious** and were created strictly for **educational purposes**, as part of a controlled, authorized phishing awareness campaign. No real logos, brands, or confidential data were used anywhere in this project.

---

This repository documents the work I did as part of a hands-on cybersecurity project: understanding how phishing works at a technical and psychological level, building a simulated phishing campaign, measuring risk by department, and translating those results into real, actionable security recommendations for an organization.

Each topic lives in its own file so it can be read as a standalone module, presented individually, or combined into a slide deck:

- `01-what is phishing`
- `02-why phishing matters`
- `03-types of phishing`
- `04-how phishing attacks`
- `05-what phishing exploits`
- `06-why everyone is vulnerable`
- `07-simulated phishing examples`
- `08-campaign results and department risk`
- `09-preventionand response`

---

## ⚖️ Ethics and usage note

- Every email, domain, and data point in this repository is fictitious or anonymized.
- Simulated phishing campaigns should **only** be run with formal, written authorization from the organization.
- This material exists for **education and awareness**, never for malicious use.

*Educational cybersecurity awareness project. Any real brand or company mentioned in the case studies is cited strictly as a matter of public record, with sources linked.*
